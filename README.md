# Dici

Dici is an alpha-stage command-line program for dictionary requests.

## Requirements

- Python 3.15 or later

## Install

From the project directory, install Dici and its dependencies:

```bash
python -m pip install .
```

For development, install it in editable mode:

```bash
python -m pip install -e .
```

## Run

Launch the command-line interface with:

```bash
python -m dici
```
